# 多帧语义位置候选：本轮结果与交付

本轮完成一个固定方法的真实实现和完整验证。正确选择从81/733（11.05%）增至93/733（12.69%），增加12题、1.64个百分点；负任务误选保持19/382（4.97%）。原1508帧的R1地图预测逐项精确不变。这是稀疏节点从建图到语义候选接口的改善，不能计为地图召回、车辆路径安全、实际到达或未见数据泛化提升。

## 固定范围与方法

基点为已推送Git `80adf9171f58c4ea58df11147f45f8f686e61078`，种子17。沿用38个已使用验证／调试场景、11个log、1508帧和原1115题（733正、382负），完整分母、原标签、3m同类一对一评价不变。原历史81个已用测试回归本轮未读取或运行。没有参数搜索、GPU、模型调用、训练或规划。

新增方法只允许无形状稀疏节点成为任务级语义位置候选：最近最多8次真实原始深度测量至少来自3个独立帧／时间、跨度至少1秒，当前帧必须有真实更新、当前支持比例至少0.4，原始测量中心的稳健速度不超过0.5m/s，启发式xy方差不超过4m²，原一对一关联来源及跨阶段竞争闭合。有未决竞争维持unknown；不跨ID合并轨迹。方差未校准，不解释为概率置信。

密集节点的原证据门、原语义解析、类别、关系、距离、分数及排序保持。新增节点只获得语义位置候选资格，仍无extent／形状，`vehicle_safety_authorized=false`。累计点数从未冒充当前帧5点：独立审计所核340个唯一历史原测量全部只有1—4点。空间关系仍基于同一预测图；GT只在方法返回后评分。
