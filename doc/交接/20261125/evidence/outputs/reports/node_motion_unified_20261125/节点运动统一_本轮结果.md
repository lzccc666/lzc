## 2. 字段的真实含义

统一节点包含稳定身份、类别、世界位置、真实传感器时间、来源／当前支持、不确定性、形状可用性以及 static/dynamic/unknown。形状仅复制原预测中实际存在的有效形状，未知维持 null。相机姿态和前向光轴仅声明为 CAM_FRONT 代理坐标，不冒充车辆后轴姿态。

`*_semantic_task_nodes.jsonl.gz` 是最终可用的任务读取视图，同时保留：

| 字段 | 含义 |
| --- | --- |
| `estimated_motion_state` | 原保存算法的运动估计（有明确来源）；原来缺失的估计仍为 unknown |
| `verified_motion_state` | 本轮真实测量来源与时间链满足冻结条件后的核实状态，可能为 unknown |
| `motion_state` | 本轮已冻结的 verified 语义，保持原样；关系／任务实验继续使用冻结字段，未事后切回估计来救分 |
| `raw_velocity_world_xy_mps` | 原始测量位置与真实时间推导的速度向量；证据未闭合时仅供诊断 |
| `motion_velocity_world_xy_mps` | 核实后可用的速度向量；unknown 时为空 |
| `body_heading_world_rad` / `body_heading_available` | null / false；速度方向不等于车辆车头或行人身体朝向 |
| `shape_available` | 是否有原预测形状，不由运动确认补尺寸 |
| `semantic_position_candidate` | 本轮 raw 静止位置资格，不等于已通过具体指令的全部语义、原 dense 深度门或道路可行性 |
| `vehicle_safety_authorized` | 全部为 false；本轮没有给无形状节点任何车辆路线安全授权 |

估计、核实与可安全规划是不同层级。字段完整不要求把旧估计抹掉，也不把未知伪装为静止。语义别名旁路逐项检查了所有旧字段与原视图完全相同。

## 3. 冻结核实规则和来源

仅使用截至当前时刻、同一内部身份来源的真实选定 mask／投影 LiDAR 测量中心。保留真实 camera capture 时间，render/group 时间单独保存；同一多相机时刻只计一个独立组。最多使用最近 8 组，至少 3 组、跨度至少 1 秒、当前确有更新、当前真实点至少 1、当前支持比例至少 0.4、来源与一对一竞争闭合、启发式 XY 方差至多 4m²。沿用 robust XY 原始速度计算与 0.5m/s 静动界线，未满足则 unknown。该方差是未校准启发式量，不是概率置信度。

稀疏→dense 及 sparse→sparse 的原分配结果、ID 与数值更新均未更改；有前阶段未解决竞争时不能声称来源闭合。不把累计点数当当前点数，不跨别名／ID拼接历史，不使用 GT 补身份、静止或形状。来源闭合是现有观测关联的保守检查，仍不证明真实身份永远正确。
