# 真实开发地图连接的车辆执行诊断

目标是补充实际车辆控制跨越已声明地图连接的证据，不把原有点路线或单车道方向审核等同于连接执行。仅使用已访问的38个允许开发场景、11个log及过去LiDAR地图上下文，不读取30个新封存场景或运行新封存方法。此协议是在查看地图和日志结构后制定的后验开发诊断，不作为独立主测试。

每场景只取既有地图消融上下文中最小frame_idx；不以方法是否成功选择帧或路线。按相机当前位置到中心线样点距离，选与相机航向夹角至多60度、距离至多10米的最近lane，距离相同按token排序。选择该lane字典序第一个lane_connector，再取该connector字典序第一个outgoing lane。不搜索其他可成功分支。缺车道、连接、短lane或不满足限制均保留一个失败任务，不换场景。总固定38任务，3种子17/29/43，2规划器共228次；固定首任务seed17/hybrid烟测后执行全量。

这是给定正确地图路线的运动学诊断：人为将后轴中心初始化到入口lane末端前8米，出口参考位姿取出口lane前10米，入口与出口均需至少6米中心线、首末车身留量。初始化点距离原相机位置大于30米时保持unknown，不改变规则补样本。该位置不冒充录制车辆的真实后轴位姿。任务没有语言/对象实例目标，参考位姿到达不是语义正确到达；记录全体任务的路线、实际运动、已声明连接过渡和参考位姿到达，语义对象选择/锁定/到达信用均为0。

地图多边形、车道方向及outgoing来自固定官方HD地图；保持孔洞和原几何，不修补未声明连接、不扩大道路。障碍只来自该上下文的当前/过去预测对象，冻结为静态快照，不读未来目标或官方对象真值；不声称对动态交通安全。入口参考位置是公开的人工运动任务条件，不声称真实感知闭环。

运动约束规划用现有前向Hybrid A*（3秒/2000扩展），点A*保留为对照。两个条件使用同一参考起终位姿、车辆、地图、静态障碍、跟踪控制与执行安全门，不以点路径角度直接驱动车辆。每次控制以同一自行车模型积分，2.7米轴距、4.6×1.85米矩形；时间步0.1秒。每步及持续制动预测均检查整车连续扫掠在车道链和可行驶交集中且不碰当前预测障碍；圆弧后轴管状包络覆盖车道或相邻连接对，连续方向证书不允许反向。车道状态只能保持或沿冻结链前进一步，切换时必须是官方outgoing且圆弧全段在两个官方端点2米范围内；不能因路口重叠直接跳到出口。

参考位姿到达需在出口lane、距参考点≤0.75米、航向≤12度、速度≤0.1米/秒并连续保持2秒。保持时间内仍检查车身、方向与连接。每试验最多900控制步，完整运行墙钟预算3600秒、新存储1GiB、至少6GiB剩余，禁用CUDA并记录共享CPU窗口。种子只扰动初始平移标准差0.03米及航向0.5度，不增加独立任务数。

执行后另以原始官方connectivity重新核对车道链、所有实际过渡/初始条件/逐控制账目与输入SHA；用独立连续车身审核重算控制积分和全段车身，方向模块对保存模型轨迹单列复核。不能只用执行器自报reference_pose_reached证明完成。缺证据或违规照常保留，未知不计成功、未行驶不计100%安全。主张范围仅为已保存静态预测与公开HD先验下的开发运动学诊断。
