# 连续零长度中心线采样的显式规范化与同预算开发实验 v2

v1全部228配对、独立实际执行和规划余量审核完成后，进一步追查60条UNKNOWN_INVALID_DECLARED_CHAIN：它们来自10个任务的中心线退化采样，而非官方连接端点超2米。17个ready任务的51条引用车道中有22条重复计数的相邻零长度边，非零但≤1e−9米的边为0；重复引用车道不增加独立地图数量。所有原始严格失败和v1结果保留。

新增`canonical_vehicle_corridor.py`只移除相邻XY浮点值完全相等的采样。原始文件只读，逐车道保存原索引、删除索引和原输入SHA；验证全部有序非零边向量完全相同、曲线集合相等、Hausdorff距离0、长度完全相等。非相邻回返点、任何非零短边均不移除；未知、无方向与仅一个不同点继续拒绝。不同第三列航向记录保留在原输入，规范化只服务XY有向曲线及其相邻非零切向，不声称对第三列全部元数据等价。

没有改变任务、官方token、连接、端点、道路/孔洞、障碍、车辆、0.05米规划余量、2米切换界、执行守卫或终点规则。两方法都使用同一显式规范化走廊；原Hybrid和引导模块保持v1字节，运行版本另立。原38任务×3固定种子×2方法仍228，全体保留；仍3秒/2000扩展、交替方法顺序，墙钟/存储预算沿用3600秒/1GiB/最低6GiB，CUDA隐藏并记录共享CPU。
