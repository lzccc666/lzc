# 保存执行的独立连续方向审核

本轮继续以实验和复现交付为先，不写论文正文或整体框架。本文是既有开发实验的后验审核协议；已查看冻结配置和少量日志结构，不冒称事前注册或新封存测试。

审核当前150规则感知试验与6个CPU真实传感器故障试验的全部保存状态，包括首次真实感知记录中的0秒车辆状态。不从随机种子重造初始姿态，不读取规划器成功标志来判断方向，不运行模型、不改变控制、不增加到达。主450完整后的全部方向审核另冻结队列，失败/缺证据保留分母。

每个保存控制步先检查时间、速度范围、曲率上限及按固定平均速度/转角圆弧模型的端点残差。采用已保存首末航向的短角差重建该模型圆弧；固定车辆条件保证单步理论转角小于π/2，否则不作航向解包。位置容差1e-6米、时间容差1e-7秒。该审核不是另一套控制动力学实现，也不代替先前独立控制/车身审核；仅对冻结积分模型的连续方向给证据。

中心线按冻结点序作为有向线段，不删除退化段或任取一个有利最近段。圆弧子区间中点和路程半径约束全部可能最近段：距离函数的1-Lipschitz性保证候选集使用最小距离+两倍半径覆盖所有可能段。对整个航向区间解析取速度单位向量与每个可能有向切线点积的最小值，包含反向极值。只有全部下界大于1e-10才发前向数值证书；距离余量1e-8米、最多12级细分。所有真实并列最近段都反向时记录违规见证；冲突、边界或预算耗尽保持unknown。附独立端点进度范围，若与前向证书矛盾则降为unknown，不挑投影。

零路程记not_exercised，未行驶不计100%方向安全。缺少首帧、非法状态、圆弧残差或其他证据缺失记unknown。方向审核不做车身包含、碰撞或动态交通证明，须与先前独立车身证据分别查看。十个冻结配置均为单向单车道，没有跨车道/路口连接，连接准确率为null、not_exercised，不把无连接任务记100%正确。真实道路离线地图消融和其连接审核另列，不能替代实际执行中的连接证据。

每个cohort先固定清单、来源摘要、车辆/配置/代码SHA，单例smoke通过后跑全量，保存逐控制步证书/违规/未知和逐试验账目。CPU预算900秒、新存储1GiB、磁盘至少6GiB，禁用CUDA，记录与主实验共享CPU窗口。按十个仿真配置聚类给实际行驶试验方向通过率区间；6故障条件仅一个任务/配置/种子，不虚造独立性或有意义的配置置信区间。原结果不改，首次失败不覆盖。
