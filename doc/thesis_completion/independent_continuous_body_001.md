# 独立控制重算与连续车身数值证书 v1

这是已完成开发仿真之后增加的独立后验审核，不是新封存方法、重新训练或新的导航执行。先审核全部150条冻结规则感知闭环（50任务、10配置、3种子），再审核已完成的六条件CPU传感器故障；无结果/无执行按未知或未执行保留，不挑成功。主450完成后以同版方法审核全部450，当前不读取未记账/活动试验。所有原结果只读，不用新几何覆盖原run或更改既有参数。

独立模块不导入或调用原step_vehicle、footprint_polygon、swept_body_polygon、audit_executed_states、setup、rectangle或规划器成功标志。原始冻结任务JSON提供车辆尺寸/限制、道路多边形、目标中心/尺寸/方向和屏障规则；障碍和道路在新模块中以标量三角函数独立重建，记录其顶点与SHA。固定道路和障碍均为原仿真的静态评价真值，仅供离线评价，不进入推理。

控制重算采用标量clip和复数中点sinc积分：限幅速度与转角后，用前后均值速度、前后均值转角得到本0.1秒步的恒定圆弧。校验全部六个保存状态量；位置1e-6m、航向1e-7rad、速度/转角1e-8、时间1e-7s，与原独立执行审计容差同阶，结果出来前固定，不按结果放宽。有限精度计算可能有残差，逐项最大值保存。首状态来自保存的第一次传感器state；不从未来结果倒推起点。记录无穷/NaN、重复时间、缺控制或状态不一致全部失败/未知，不删除间隔。

连续几何采用不同于原“端点凸包+弓高”的实现。对每个恒定圆弧时间子区间，在中点用标量变换建立矩形；任何车身点相对中点的位移至多(v+R*|omega|)*半区间时长，其中R为后轴到最远角点距离。矩形各边向外偏移该界（miter包络）并加固定2e-6m数值余量，保守覆盖这段连续车身。若包络完全被道路包含且与所有静态障碍不相交，记certificate_safe；若实际中点矩形越界/接触障碍，保存圆弧时刻与顶点作witness_violation。否则继续二分，最多深度12；到限仍无法证明，记unresolved，不能记安全或确定碰撞。整条轨迹只有全部状态/控制有效且全部间隔获证才能获连续车身通过。

这是双精度GEOS下、明确余量的保守数值证书，不声称形式化区间算术或真实物理证明。复用Shapely/GEOS几何库，但不复用原车身/扫掠/积分实现。证书限定保存控制、分段恒定平均运动模型、固定矩形车身、冻结静态道路/障碍，不能外推动态交通安全、轮胎动力学、路线拓扑方向或语言身份。它不自行产生选对对象、稳定锁定、路线或实际到达；原到达与本证书交叉报告，不增加任务/到达数。

预算：CUDA不可见，CPU共享；一次执行最多900秒、1GiB新增产物、至少6GiB磁盘余量，先单位边界测试和一个固定首任务试跑再全部150+6；记录主矩阵资源事件。主450审核等待器不占GPU，完整summary/全部记录指纹齐备后才执行，后验结果保留失败/unknown。核验输入执行/感知首状态/任务release/结果SHA、所有区间计数和证据顶点；全部固定失败保留，不覆盖原审核。
