# 全序列身份与可见间隔返回诊断 v1（开发后验补充）

本诊断使用已完成的38开发场景、11采集log、1508帧、七种固定预测；不训练、不重新推理、不调参数、不访问新封存方法结果。它在已有相邻匹配身份变化结果之后设计，是开发后验补充，不得称事前注册独立主表。所有阶段与Goal仍false。

每个场景独立计算整段对象身份的一对一最大重合：每帧同粗类别、XY中心距离不超过既有3米门限的所有GT—预测边累计为轨迹间潜在重合次数；全序列一对一最大累计重合给IDTP，IDFN=全部官方观测−IDTP，IDFP=全部预测观测−IDTP。IDR=IDTP/GT观测、IDP=IDTP/预测观测、IDF1=2IDTP/(GT+预测观测)。基础框架参考TrackEval官方Identity实现，实际使用的是3米中心门限适配，不是nuScenes官方tracking成绩、MOT二维IoU成绩或人工实例标签。GT与预测皆空时分母无定义保留null，不给100%。

七方法的GT分母均固定5723跨帧观测；缺失首帧和未能匹配均保留。单帧基线没有跨帧身份，每帧节点ID加帧前缀，避免偶然复用数字获得跟踪信用；其它方法用保存的稳定节点身份，不擅自重连轨迹。官方实例和完整序列身份分配只在隔离离线评价中使用，不传给建图/语义/导航/训练/缓存。

主要门限支持可能歧义：同一GT或预测在一帧存在多个合法门限邻居时，统计其观测与边数。另给唯一门限支持敏感性，只有该帧GT和预测各自都只有一个合法邻居时才累计支持；全部GT/预测分母不变，不把歧义样本移出。它是更保守的支持，不证明其它边必错，也不消除3米中心近似。原官方GT时间比相机晚约33–42毫秒的近似继续披露。

相邻匹配身份变化仍采用原每帧固定中心一对一关联，原有30/615及44/1312口径保留，不用全序列身份分配替换它。IDF1受检测/定位覆盖影响，不能仅因IDF1上升宣称跨帧身份稳定性全面提升。

官方列表返回机会：某实例在帧i出现、连续至少一个中间帧不在当前官方可见评价列表、于帧j再次出现。所有方法共享同一GT事件分母；分别记录前端点/返回端点匹配、两端都匹配、身份相同、身份改变与身份未知，未知不冒充确定错合并。间隔按相机真实秒数，额外固定2秒分组源自现有TTL设计，不根据结果选择。官方列表缺席可能是视域、可见性或采样定义，不能断言真实遮挡。

方法匹配返回：同一实例在两次成功中心关联之间至少一个中间帧未匹配，分官方列表连续存在与列表缺席混合；相同/改变只对两端已关联的返回事件条件统计。没有再次匹配、场景结束或GT离开列表的尾段另列，不能默默移出并宣称恢复成功，也不把无后续观察视为已知永久丢失。

所有主比率按原11采集log配对4000次bootstrap、固定seed17；帧、边和重复方法不增加独立样本。保存逐场景/方法/门限支持条件的整数计数、轨迹分配、返回事件及逐logCSV。计算预算CPU900秒、1GB新增存储、至少6GB可用空间；明确记录与主矩阵共享CPU的窗口。先合成边界测试和小规模开发试跑，再执行全量，全部失败保留。

参考验证：在输出目录隔离下载TrackEval官方Identity及最小依赖和LICENSE，预算不超过1MiB，固定commit/SHA；无pip安装、不改原环境。若旧参考仅因np.int被新NumPy删除而不能运行，保留原字节，仅在独立兼容副本改成int并记录精确差异；不改方法或门限。用官方扩展FN/FP代价矩阵参考对照本项目最大重合实现，并独立重算门限边和统计。参考运行前不根据结果改门限或筛选场景。
