# 代码模块与调用链

## 一条指令怎么变成路线

```text
图像 + 激光雷达 + 相机参数 + 车辆位置
    ↓
检测和分割：哪里有车、人等对象
    ↓
深度处理：这些对象离车多远，距离证据是否足够
    ↓
持续建图：上一帧和这一帧是不是同一个对象
    ↓
关系图：对象彼此的左右、前后、附近关系
    ↓
规则 / CLIP / 可选Qwen：理解指令并给出目标候选
    ↓
确定性检查：目标是否可信，附近能否安全接近
    ↓
车辆规划与控制：路线、转向、速度、执行状态
```

Qwen不负责计算对象三维位置，不改变地图几何，不直接掌控方向盘。生成路线、选对对象、锁定正确、实际到达是不同结果。

## 文件索引

| 模块 | 实际代码位置 | 输入 → 输出 |
|---|---|---|
| 检测、分割 | `conceptgraph/scripts/streamlined_detections.py` | RGB → 框、类别、掩膜、图像特征 |
| 真实前端保存 | `conceptgraph/completion/frontend.py` | 图像等输入 → 固定的真实检测/分割记录 |
| 深度与证据 | `conceptgraph/completion/depth.py`、`conceptgraph/slam/streamlined_mapping.py` | 掩膜、深度 → 三维点与距离证据 |
| 增量对象地图 | `conceptgraph/slam/streamlined_mapping.py`、`conceptgraph/slam/mapping.py` | 当前观测、过去对象 → 更新后的对象地图 |
| 一对一匹配评价 | `conceptgraph/completion/association.py`、`quality.py` | 预测对象、隔离的标准答案 → 对应关系与指标 |
| 关系和增量维护 | `conceptgraph/scenegraph/relations.py`、`incremental_graph.py` | 对象位置、时效 → 关系边 |
| 规则理解和检索 | `conceptgraph/navigation/semantic.py` | 指令、对象图 → 解析与候选排序 |
| Qwen三个任务 | `conceptgraph/vlm/qwen_semantic_delegate.py`、`schemas.py` | 指令/目标小图/候选名单 → 解析/属性/排序 |
| Qwen推理与缓存 | `conceptgraph/vlm/qwen_vl_chat.py`、`qwen_cache.py` | 请求、模型 → 回答、时间与缓存记录 |
| 目标与接近位置 | `conceptgraph/navigation/target_selector.py`、`pipeline.py` | 候选、道路与障碍 → 可接近目标和规划结果 |
| 车辆路线 | `conceptgraph/navigation/vehicle_planner.py`、`vehicle_geometry.py` | 起终点、车辆外形 → 路线与车身检查 |
| 车道约束 | `conceptgraph/navigation/lane_constraints.py`、`lane_geometry.py` | 车道方向、连接 → 合法通行检查 |
| 连续状态与重规划 | `conceptgraph/navigation/online.py`、`state_machine.py`、`replan_policy.py` | 连续观测、当前状态 → 等待/锁定/重规划/终止 |
| 训练命令 | `scripts/train_qwen_lora_semantic_delegate.py`、`train_qwen_lora_semantic_delegate_v2.py` | 训练JSONL、基础模型 → Adapter与训练日志 |
| 核心评价工具 | `conceptgraph/completion/` | 固定预测、隔离标准答案 → 汇总和失败分类 |
| 后期实验驱动脚本 | `scripts/experiment_archive/public_20261115/` | 各冻结协议 → 相应实验记录；归档入口 |
| 配置 | `conceptgraph/hydra_configs/` | 模型、地图、导航、Qwen开关 |
| 自动检查 | `tests/` | 构造输入 → 功能和回归检查 |

逐文件位置见 `源码文件索引.csv`。第三方感知、基础模型、ConceptGraphs原框架与本项目新增实现需要分别归属，不能把整个目录算作原创。

## 不同实验没有自动等价

公开数据实验可以离线依次输入每帧，评价地图和目标选择。它不允许车辆的动作改变原始图像，因此不等于真实闭环开车。实际控制、锁定和到达要看独立的CARLA回合证据，不能用公开数据集上一条路线代替。
