# 数据输入与划分

## “转换后的输入”用人话说是什么

nuScenes原始数据把相机图片、激光雷达点、时间、相机参数和车辆位置分开存。我们的程序每次处理一帧，需要同时拿到这些东西。因此预处理主要做：找到对应图片，选当时或更早的激光雷达，把点投到图片上形成距离图，并整理相机参数、位置和来源清单。

这叫“整理成程序能逐帧读取的格式”，不是生成新的实拍数据，也不是建图结果。深度图是输入测量；对象地图是程序处理后生成的输出。nuScenes输入不使用未来激光雷达补当前帧；当时没有足够距离证据就保留缺失。

常见格式：

```text
dataset/processed/nuscenes/validation/converted/scene-0012/
├── color/000000.jpg       当帧图片
├── depth/                从真实激光雷达得到的距离图
├── intrinsics.txt        相机参数
├── poses.txt             各帧相机/车辆位置与姿态
└── frame_alignment.json  每帧用了哪份图片、激光雷达和时间
```

具体扩展名和辅助文件以对应目录为准；不把不存在的图层或文件冒称已输出。

## 输入目录

| 内容 | 新入口 | 说明 |
|---|---|---|
| nuScenes原始图片、官方表 | `dataset/raw/nuscenes_trainval/` | 原实体仍是 `dataset/nuscenes_trainval_raw/`，只下载本项目需要的部分 |
| nuScenes mini | `dataset/raw/nuscenes_mini/` | 历史数据，不作为新增独立样本 |
| nuScenes验证／调试输入 | `dataset/processed/nuscenes/validation/converted/` | 38场景、1508帧的建图消融所用场景组；不是完整Qwen训练集 |
| nuScenes测试输入 | `dataset/processed/nuscenes/test/converted/` | 30场景、1196帧；方法冻结后测过，现已开启 |
| KITTI连续输入 | `dataset/processed/kitti/tracking/` | 共享卷已有连续序列输入的入口 |
| KITTI下载文件与标注 | `dataset/raw/kitti_tracking_downloads/`、`kitti_tracking_labels/` | 共享卷已有档案；标注只供监督/评价，不送入正式推理 |
| 当前新Qwen训练数据 | `dataset/qwen/real_graph_v003/` | 459训练、171验证、108开发测试样本 |
| 其他Qwen数据版本 | `dataset/qwen/official_graph_v001/` 等 | official版本是官方图辅助诊断，不能当真实感知表现 |
| 历史预处理与审核记录 | `dataset/processed/preparation_history/` | 保留各版本及时间对齐、来源报告 |
| 人工指令与属性审核 | `dataset/annotations/` | 是单独记录，不表示全部训练样本都经过人工审核 |

## 训练、验证、测试不能混称

| 新名称 | 实际用途 |
|---|---|
| 训练集 | 确实用来更新Qwen Adapter参数的数据，见 `real_graph_v003/train.jsonl` |
| 验证集 | 训练期间选检查点，见 `real_graph_v003/validation.jsonl` |
| 验证／调试场景组 | 做建图消融、检查错误和选方法的38场景；旧代码称development |
| Qwen验证／调试子集 | `development_holdout.jsonl`，108条、12帧；有被查看的历史，不能冒充未见最终测试 |
| 测试场景组 | 冻结后评价的另外30场景；旧代码称sealed，新入口称test |

Qwen的459条训练样本来自51帧，不是459个画面。9类模板从同一帧生成；逐行索引见同目录 `Qwen样本划分索引.csv`。不能把38个调试场景全部改名为训练集，也不能在整理时改写原JSONL的split字段或把历史测试并入训练。

注意：KITTI官方下载包名里的training表示“官方提供标注的部分”。它不自动代表本项目拿来微调了Qwen，本项目使用的是其中的连续序列来做建图评价。具体选取以冻结selection为准。

## 每帧如何找到结果

输入中保留scene和frame编号；结果也按scene和frame组织。请从 `outputs/results/` 进入，而不是把 `dataset/processed/` 误当成输出目录。详细格式见 [结果目录](04_结果与逐帧目录.md)。
