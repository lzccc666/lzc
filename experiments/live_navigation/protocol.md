# 可启动与控制的感知导航交互入口001

范围：开发演示与复现，不开启新封存、不改原主450/缺一450/故障/性能release，不新增人工记录，不写论文正文。新增独立入口，现有8768审核服务不改。

沿用冻结synthetic_tasks_v1的50任务/10配置/三种子，只允许选择原任务及17/29/43，不接受任意路径、模型或评估标签。仅CPU YOLO/SAM/CLIP、OSMesa llvmpipe、原PerceptionVehicleAgent和原车辆执行器；原样读取实际当前RGB/稀疏LiDAR，agent只收到道路先验、指令和当前观测，目标身份/区域/屏障GT仅在环境与独立评价端。无Qwen调用、GPU性能或新独立场景信用。

提供开始、每次推进0.5仿真秒、连续运行、暂停、停车并结束。暂停冻结仿真时钟，速度状态保留，不声称车辆已刹停。停车用原制动界限与0.1秒状态积分直至零速，保存真实命令和状态；前端忙时命令排队，固定逻辑时钟不冒称实时异步。初始相机观测与每5次控制后的相机观测均重新渲染并真实跑前端，绝不读取主矩阵帧代替新推理。

每次启动独立run-id和release；命令追加保存，状态JSON原子替换，输入/前端/crop/感知/执行/独立终点结果保存到interactive_simulation/live_navigation_sessions_001/。服务只允许一个实际活动worker；重启用PID与start_ticks检查已有worker，不自动重跑旧会话。已失败与停止运行均保留。

单会话预算：900秒墙钟、30秒仿真、80真实前端、500MB新增、至少6GB空闲；单CPU线程、隐藏CUDA、离线模型。预算停止同样制动，异常保存失败而非补成功。暂停也计墙钟预算。实际测试先1个预定config00-positive0/seed17的单步/运行/暂停/停车；通过后可验证不同任务正常终止，不以成功筛选。浏览器桌面/手机实际操作并核对保存命令、位姿、RGB/深度变化、冻结暂停和零速停止；自动化操作来源明确，不能称真人标注。

到达由预定身份、独立区域、航向、速度、2秒保持和无违规共同判定；路线、曾Top1正确、连续3帧正确锁定、实际到达分开。用户中断不记到达。终止后独立重算全部保存状态，初态原样保存，不使用事后种子重建补证。本交互运行不并入冻结主表。连续安全范围限声明合成静态道路/车辆模型。
