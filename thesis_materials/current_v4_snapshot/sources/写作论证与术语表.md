# 写作论证与术语表

中心论证：在公开录制道路数据与已知位姿/地图先验下，因果观测、深度质量与对象维护能够改善当前开发建图；对象关系、保守语言选择及点路径与车身可行性之间仍存在明显缺口，必须以分层证据报告。

第1章从道路对象、语言歧义及几何执行差距提出问题；第2章定义各层表示与假设；第3章约定接口、标准答案来源和评价隔离；第4、5章分别给出实际代码对应的方法；第6章用建图、身份、关系、检索、专项、消融、地图及外部诊断逐层检验；第7章只总结已证实的范围并列出缺口。

监督类型分别登记：官方类别/位置/实例身份；官方几何规则关系；官方类别自动匹配弱监督；构造指令和符号候选答案；独立GT对象/区域参考。自动生成部分未经人工审核。评价端GT不输入方法；地图诊断给定正确参考目标单独声明。

统计原则：百分数明确分母，匹配误差声明条件，unknown不删除；重复条件记录不能增加独立场景数。nuScenes区间按log聚类；Qwen按真实log或符号bank分别处理，排序独立语义证据小于180条记录。负结果与跨零区间保留。

贡献归属：已有YOLO、SAM、CLIP及Qwen能力明确归属于原工作；本稿陈述项目实际观测整理、关联维护、接口适配与诊断，不使用“首次”“全面领先”等无比较证据措辞。
