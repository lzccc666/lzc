# 论文资料入口

- `project_guide/`：项目框架、各模块作用、源码索引、输入输出和实验目录说明。
- `originals/`：原始Word和第1—3章草稿的链接，原件不改动。
- `existing_draft/`：已有公开数据集稿件的历史版本，本轮未改写，不表示内容已经全面核验。
- `tables/`、`figures/`：已有实验结果表和图，引用时核对对应统计分母与版本。
- `historical_handoffs/`：历史写作和交接材料，需要结合当前结果检查，不能将旧结论自动当最新结论。

先看项目根目录 `项目导航.md`。本轮做目录整理和方法说明，不撰写新的论文正文。
