# 官方实例核验页使用方法

1. 在 Windows 资源管理器中直接双击 `index.html`，不需要启动服务器。
2. 页面中红色十字是原填写者点击的位置，彩色框是官方车辆标注投影。
3. 选择你实际看到的情况：
   - 与某个官方车辆框匹配；
   - 看到了目标，但官方框没有覆盖；
   - 没有看到所说的黑色轿车；
   - 画面太远或太模糊，无法判断。
4. 在“依据”框写一句人话，例如“点击位置附近能看到远处黑色车辆，但太小，无法确认是不是轿车”。
5. 点击“下载核验记录 JSON”，把下载的 JSON 文件发回即可。

这次核验只用于确认人工看到了什么，不会自动修改模型结果，也不会自动把记录加入封存测试。
