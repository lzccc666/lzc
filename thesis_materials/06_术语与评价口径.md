# 术语与评价口径

| 统一术语 | 含义 | 不可混同 |
|---|---|---|
| 生成路线 | 规划器输出路径 | 实际执行成功 |
| 选对对象 | 独立关联到可接受实例 | 选择了任意系统目标 |
| 正确锁定 | 在时序确认要求下锁定正确身份 | 单帧高分/曾经选对 |
| 实际正确到达 | 身份、独立区域、实际车辆姿态/速度与保持时间同时满足 | 仅到达规划器自己选出的点 |
| stable_object_id | 系统内对象轨迹ID | 官方instance ID |
| 官方实例关联 | 用独立官方标签/几何门限关联预测 | 人工身份真值或无误差GT |
| 新Adapter | 独立数据/训练版本，比较时应带种子与release | 旧best_adapter或任意新权重 |
| schema通过 | 输出结构符合契约 | 语义正确或成功应用 |
| 实际应用 | 经身份/版本/时效/安全核验进入当前选择 | 后台返回、改变排序或改变最终目标 |
| 配置/采集log聚类 | 统计重采样单位 | 帧、模型调用、种子或重复试验均独立 |
| 显式初态重建 | 用声明初态/种子恢复缺失状态以计算证书 | 实际保存的零时刻观测 |
| 缓存复跑 | 同冻结请求的命中/新增调用账目 | 新准确率样本或新的场景 |
| 新环境复现 | 实际独立venv中的完整任务与重算 | 新操作系统、Windows已验证或仅脚本可运行 |

位置/距离以米、速度以米每秒、时间以秒报告；角度须明确弧度/度。差值若乘100则为百分点，不能写成相对增长百分比。每条数据以实际release为准，未知保留unknown/null，不填0。
